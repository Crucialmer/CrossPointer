===========================================================
  CrossPointer 🎯 极简屏幕十字辅助线 - 快速使用指南 (v1.0)
===========================================================

【软件定位】
CrossPointer 是一款参考 macOS 26 (Tahoe) Liquid Glass 设计美学的极简、
原生 C++20 Windows 屏幕十字辅助线工具，专为表格数据审阅、代码对齐、
UI 设计参考而生。本软件为 100% 纯绿色便携单文件：
- 解压即用，无需安装，零外部运行库依赖。
- 零注册表垃圾，零外部目录文件残留。
- 所有配置（CrossPointer.ini）严格保存在本文件夹内。

-----------------------------------------------------------
【核心特性】
1. 全链路 macOS 26 (Tahoe) Liquid Glass 视觉统一：
   - 定制托盘右键弹出菜单：无边框圆角液态玻璃卡片、顶部同心状态卡片
     （发光呼吸状态点 + 版本号）、SF-Symbols 风格矢量图标、蓝色胶囊悬停高亮、
     右侧快捷键提示与键盘导航，自动适配系统浅色 / 深色主题。
   - 独立「软件更新」液态玻璃窗口 + 实时下载进度：
     • 支持启动后台静默检查，发现新版本自动提醒；
     • 下载阶段内嵌 6px 圆角胶囊进度条，实时刷新已下载大小、百分比与下载速率，
       支持随时取消下载与一键原地安全热替换重启。
   - 独立「关于软件」液态玻璃卡片与全套模态提示弹窗：
     • 左上角 macOS 红灯关闭按钮、可拖拽移动、核心特性玻璃卡片与可点击 GitHub 链接；
     • 重载配置、热键冲突、单实例运行提示等全面采用 Liquid Glass 光学圆球弹窗。
   - 偏好设置面板提供全抗锯齿液态玻璃、右对齐 macOS 胶囊开关、自定义滑块与
     实时准星画卷预览。

2. 零待机功耗与 240Hz 零阻塞 Direct2D 渲染引擎：
   - 隐藏在托盘时自动关闭跟踪定时器并释放 1ms 硬件时钟中断，待机 0% 唤醒。
   - Direct2D 立即呈现模式，消除多窗口串联 VSync 阻塞，跨屏 8K 无损动态缩放。

-----------------------------------------------------------
【默认交互快捷方式】
• 切换显隐快捷键：Shift + Alt + E（可在设置中自定义，支持与退出设为同一键）
• 退出程序快捷键：Shift + Alt + Q（可在设置中自定义，支持与显隐设为同一键）
• 系统托盘操作：
  - 单击托盘图标：切换十字线显示 / 隐藏
  - 双击托盘图标：打开 macOS 26 Liquid Glass 偏好设置面板
  - 右键托盘图标：呼出 macOS 26 Liquid Glass 自定义托盘菜单
